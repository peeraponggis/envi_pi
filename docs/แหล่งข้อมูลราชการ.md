## ข้อควรระวังรวม

- **HTTP-only** (Air4Thai, gistdaportal, wms.nso, RID) — ยิงจาก Edge Function ได้ แต่เบราว์เซอร์บน https ยิงไม่ได้ (mixed content)
- **CORS** — ไม่มี endpoint ไทยตัวไหนประกาศ CORS → ข้อมูลไทยผ่าน DB ทั้งหมด
- **ค่าเป็น string + sentinel** (-1, -999, "", "-") → `num()` ตัวเดียว ห้ามเก็บ -999 ลง `value`
- **พ.ศ. / เวลาไทยไม่มี TZ** → `parseThaiDate()` / `thaiDateTimeToISO()` ลบ 543 เมื่อปี > 2400 และต่อ +07:00
- **ArcGIS 1000 แถว/ครั้ง** · **DGR 117k แถว** → cursor ใน `ingest_runs`
- **ลิขสิทธิ์** — HII CC BY-NC · LDD CC BY-NC-ND (ห้าม simplify) · ทุกแหล่งต้องแสดงเครดิต (ดูแถบล่างขวาของแผนที่)
- **endpoint ไม่มีเอกสาร** (GISTDA PM2.5, Royal Rain, Air4Thai) → handler fail-soft บันทึก `ingest_runs.error`
