## สถาปัตยกรรม

```
[หน่วยราชการ JSON/RSS/ArcGIS] ──▶ Edge Function `envi-ingest` (Deno, service_role) ──▶ Postgres (PostGIS)
        ▲ pg_cron → net.http_post (token ใน Vault)                                        │
[SHP/CSV] ─ npx mapshaper → GeoJSON ─▶ web/import.html (admin ล็อกอิน, ชุดละ 500) ────────┤
[NASA POWER / PVGIS / GIBS / Nominatim] ─ เรียกสดจากเบราว์เซอร์ → แคชลง api_cache ────────┤
                                                                                           ▼
                                       web/index.html (Cesium) ◀── RPC site_report / nearest_stations / วิว GeoJSON
```

- **โปรเจกต์ Supabase ใหม่** (ผู้ใช้สร้างเองใน Dashboard — ชื่อเสนอ `envi-pi`) · ใช้ schema **`public`** ได้เลยเพราะเป็นโปรเจกต์เฉพาะ (ไม่ต้องเพิ่ม Exposed schemas) แต่ยังต้องรัน grant เอง (โปรเจกต์หลัง 30 พ.ค. 69 ไม่มี default privileges)
- **PostGIS เปิด** (`create extension postgis with schema extensions`) เพราะต้องตอบ 3 คำถามหลักของ site report: สถานีใกล้สุด (KNN), เหตุการณ์ในรัศมี (`ST_DWithin`), จุดตกในโพลิกอนป่า/ลุ่มน้ำ/การใช้ที่ดิน (`ST_Contains`) · ฟังก์ชันทุกตัว `set search_path = public, extensions`
- **Edge Function ตัวเดียว `envi-ingest`** รับ `{source}` แล้ว switch handler ต่อแหล่ง (air4thai, gistda_pm25, gistda_hotspot, tmd_quake, dgr_wells, royalrain, …) · ตรวจ header `Authorization: Bearer <ENVI_CRON_TOKEN>` · เขียนด้วย `.upsert(rows,{onConflict})` · บันทึก `ingest_runs` ทุกครั้ง fail-soft (ไม่ throw ให้ cron ค้าง) · มี `VERSION` ใน log
- **Secrets**: ENVI_CRON_TOKEN, TMD uid/ukey/JWT, GISTDA api_key, FIRMS MAP_KEY → Dashboard → Edge Functions → Secrets · token ฝั่ง cron → `vault.create_secret()` ใน SQL Editor · **ห้ามเขียน secret ลงไฟล์**
- **Front-end**: ไคลเอนต์ supabase ตัวเดียว (`getClient()` cache Promise) · แหล่งไทยทุกตัวอ่านจาก DB เท่านั้น (HTTP-only/CORS) · แหล่งต่างประเทศเรียกสด + `api_cache` (ttl 30 วัน, key ปัดพิกัด 2 ตำแหน่ง)

**RLS (ทุกตาราง)**
- `anon` + `authenticated`: `select` บน sources, stations, observations*, latest_observations, events, layers, layer_features, api_cache (สมมติฐาน "เว็บสาธารณะ" — ถอด policy anon ได้ในไฟล์ `…_rls.sql` ไฟล์เดียว)
- เขียนตารางข้อมูลราชการ: **service_role เท่านั้น** (Edge) ยกเว้น `layers/layer_features/events(manual)/stations(manual)` ให้ role admin/editor เขียนผ่านหน้า import · `api_cache` authenticated+anon insert/update (แคชสาธารณะ ไม่มีข้อมูลส่วนตัว) · `site_assessments` เจ้าของ rw, admin อ่านทั้งหมด · `ingest_runs` admin อ่าน

**RPC** (`security definer`, `set search_path = public, extensions`, `revoke execute from public` แล้ว grant ให้ anon/authenticated)
- `nearest_stations(p_lat, p_lng, p_radius_m default 50000, p_source default null)` → station + distance_m + latest jsonb
- `site_report(p_lat, p_lng)` → jsonb `{air, pm25_sat, hotspots_10km_7d, quakes_300km_30d, wells_5km, landslides_10km, layer_hits[], solar_cache}`
- `layer_features_bbox(p_layer, p_minx, p_miny, p_maxx, p_maxy)` → GeoJSON FeatureCollection (จำกัด 2,000 ฟีเจอร์, simplify ตามซูม)
- `save_assessment(p_name, p_lat, p_lng, p_report, p_ref_note)` → uuid (ต้องล็อกอิน)

## ความเสี่ยง/ข้อควรระวัง

- **HTTP-only** (Air4Thai, gistdaportal Tambon) ยิงจาก Edge ได้ แต่ห้ามจากเบราว์เซอร์ https (mixed content) → ข้อมูลไทยผ่าน DB ทั้งหมด
- **CORS** ของ GISTDA pm25/TMD ไม่ยืนยัน → ออกแบบให้ผ่าน Edge ทั้งหมด; สดเฉพาะ NASA/PVGIS/Nominatim/ArcGIS
- **ค่า string + sentinel** (-1, -999, "", "-") → `num()` ตัวเดียวคืน null + quality='missing' ห้ามเก็บ -999
- **วันที่ พ.ศ. / ไม่มี TZ** → `parseThaiDate()` ลบ 543 เมื่อปี > 2400, ตีความเป็น Asia/Bangkok
- **ArcGIS 1000 แถว/ครั้ง** → วนจน `exceededTransferLimit=false` · **DGR 117k** → cursor ใน ingest_runs หลายรอบ (Edge จำกัด CPU ต่อรอบ)
- **ปริมาณ** Air4Thai ≈ 10M แถว/ปี → hourly 180 วัน + rollup รายวัน
- **endpoint ไม่มีเอกสาร** (GISTDA pm25, Royal Rain, Air4Thai) → fail-soft + แจ้งใน ingest_runs.error
- **ลิขสิทธิ์** HII/LDD = CC BY-NC(-ND) → เก็บ `sources.license` และแสดงเครดิตบนแผนที่ · LDD ND ห้าม simplify รูปทรงตอนแสดง (ใช้ต้นฉบับ)
- **Edge editor ไม่มี git** → สำเนาใน `supabase/functions/` + `VERSION` ใน log เสมอ
- **`extensions.` prefix** ของ PostGIS ใน generated column — ลืมแล้ว SQL ล้มใน SQL Editor
- **ห้าม createClient ซ้ำ** (บทเรียนจาก pi-core.js)
- **ทดสอบ SQL**: PostGIS ไม่มีใน PGlite → ทดสอบ SQL บนโปรเจกต์ Supabase จริง (ใช้ `ตรวจสภาพ.sql`); ทดสอบตรรกะ JS ด้วย `node --test`
