# envi_pi — ระบบนำเสนอข้อมูลผลกระทบด้านสิ่งแวดล้อม ประเทศไทย

แผนที่ 3D (Cesium) ที่รวมข้อมูลสิ่งแวดล้อมจาก **หน่วยราชการไทย** รอบพิกัดที่เลือก:
คุณภาพอากาศ (กรมควบคุมมลพิษ) · ฝุ่นดาวเทียมและจุดความร้อน (GISTDA) · แผ่นดินไหว (กรมอุตุฯ) · น้ำบาดาล (กรมทรัพยากรน้ำบาดาล) · ดินถล่ม (กรมทรัพยากรธรณี) · ป่าสงวน/ลุ่มน้ำ/การใช้ที่ดิน (กรมป่าไม้/กรมทรัพยากรน้ำ/กรมพัฒนาที่ดิน) · แสงอาทิตย์ (NASA POWER / PVGIS / พพ.)

พัฒนาต่อจากต้นแบบ `solar energy potential based on satellite data V2.9.0.html` โดยแทนค่าจำลองทั้งหมดด้วยข้อมูลจริงที่เก็บใน Supabase (PostGIS)

## โครงสร้าง

```
web/            หน้าเว็บ (plain HTML + ES module ไม่มี build) — index.html แผนที่ · import.html นำเข้าไฟล์ (admin)
supabase/       SQL ติดตั้ง (รันใน Dashboard SQL Editor ตามลำดับ) + Edge Function envi-ingest
docs/           แผนระบบ · แคตตาล็อกแหล่งข้อมูลราชการ (ตรวจสอบแล้ว) · ขั้นตอนติดตั้ง
test/           node --test
```

## เริ่มใช้งาน

1. ทำตาม [docs/ขั้นตอนติดตั้ง Supabase.md](docs/ขั้นตอนติดตั้ง%20Supabase.md) (สร้างโปรเจกต์ → รัน SQL → deploy Edge Function → ตั้ง cron)
2. กรอก `web/js/config.js` (Project URL + publishable key)
3. เปิดหน้าเว็บ:

```bash
node scripts/serve.mjs
```

แล้วไปที่ http://127.0.0.1:5500/web/index.html

4. ทดสอบตรรกะ:

```bash
node --test test/*.test.mjs
```

## แหล่งข้อมูล

ดู [docs/แหล่งข้อมูลราชการ.md](docs/แหล่งข้อมูลราชการ.md) — แยกเป็น API เปิด / ต้องสมัคร key / ไฟล์นิ่ง / มีแต่หน้าเว็บ พร้อม endpoint ที่ยิงทดสอบแล้ว (3 ก.ย. 2569) และสัญญาอนุญาต

ข้อมูลทุกชุดเป็นของหน่วยงานต้นทาง — ระบบแสดงเครดิตบนแผนที่ตามที่สัญญาอนุญาตกำหนด
